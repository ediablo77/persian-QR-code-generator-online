# 📱 سازنده حرفه‌ای کیو آر کد

یک ابزار آنلاین، رایگان و حرفه‌ای برای ساخت کیو آر کد با قابلیت‌های پیشرفته

## ✨ امکانات

- 📝 ساخت QR کد از متن دلخواه
- 🔗 ساخت QR کد از لینک‌های وب
- 📞 ساخت QR کد از شماره تلفن
- 💬 ساخت QR کد برای واتساپ (همراه با پیام)
- 📶 ساخت QR کد برای اتصال خودکار به وای‌فای
- 📏 قابلیت تغییر اندازه QR کد (۱۵۰ تا ۶۰۰ پیکسل)
- 💾 دانلود QR کد با کیفیت اصلی
- 📱 کاملاً ریسپانسیو و سازگار با موبایل
- 🚀 سبک و سریع با استفاده از Bootstrap 5

## 🛠️ تکنولوژی‌ها

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- QRCode.js

## 🚀 نحوه استفاده

1. نوع محتوای مورد نظر خود را انتخاب کنید (متن، لینک، تلفن، واتساپ، وایفای)
2. اطلاعات را در فیلدهای مربوطه وارد کنید
3. روی دکمه "ساخت کیو آر کد" کلیک کنید
4. در صورت نیاز اندازه QR کد را تغییر دهید
5. با کلیک روی دکمه دانلود، تصویر را ذخیره کنید
